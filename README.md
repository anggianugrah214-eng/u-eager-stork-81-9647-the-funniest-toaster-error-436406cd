The funniest error message a kitchen toaster would show its owner, in one line of 82 characters. A small Node program writes the line to `/output/entry.txt`, where the house judge reads it.

The line: a toaster that has adopted the bread forgotten in its slot since Tuesday — and now refuses to toast it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
